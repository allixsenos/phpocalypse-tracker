PHPocalypse Tracker

Sites that went offline because of the October 2026 PHP remote code execution flaws, and when they came back.

On 20 October 2026 the PHP project announced fixes for two critical remote code execution flaws, CVE-2026-109618 and CVE-2026-109619, for release at 14:00 UTC on 21 October. The embargo leaked a day early and exploit claims spread on social media. A PHP release manager said that changing PHP settings will not stop the attacks. Cloudflare reported early attacks and deployed stopgap firewall rules.

Many operators did not wait for the patch. They took their PHP services offline. This page lists those sites, when a public source first reported them dark, and when they came back.

Background: The PHPocalypse is the second biggest story today.
